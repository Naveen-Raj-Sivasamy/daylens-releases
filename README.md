# Team Management Support (TMS) — downloads

Your team's daily status, leave, tickets, meeting notes, reminders and
reports. Everything your team logs is kept in a Google Sheet in your own
Google Drive. Nobody else can see it.

## Download

- **Windows:** [TMS-Setup.exe](https://github.com/Naveen-Raj-Sivasamy/tms-releases/releases/latest/download/TMS-Setup.exe)
- **Mac:** [TMS-Setup.dmg](https://github.com/Naveen-Raj-Sivasamy/tms-releases/releases/latest/download/TMS-Setup.dmg)

What's new in each version is listed under
[Releases](https://github.com/Naveen-Raj-Sivasamy/tms-releases/releases).
Once TMS is installed, it updates itself and asks before restarting.

## Getting started

- **Team admin:** open TMS → **Create a new team**. The app walks you
  through it, in about 5 minutes.
- **Teammates:** open TMS → **Join my team**, then paste the invite code
  from your admin's message.

This repository only holds the installers.
