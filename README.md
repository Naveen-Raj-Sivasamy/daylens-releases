# Daylens — Work & Status Reports

Your team's daily updates, leave, tickets, meeting notes, reminders and
reports, in one desktop app. Everything your team logs is kept in a
Google Sheet in your own Google Drive. Nobody else can see it.

## Download

- **Windows:** [Daylens-Setup.exe](https://github.com/Naveen-Raj-Sivasamy/daylens-releases/releases/latest/download/Daylens-Setup.exe)
- **Mac:** [Daylens-Setup.dmg](https://github.com/Naveen-Raj-Sivasamy/daylens-releases/releases/latest/download/Daylens-Setup.dmg)

What's new in each version is listed under
[Releases](https://github.com/Naveen-Raj-Sivasamy/daylens-releases/releases).
Once Daylens is installed, it updates itself and asks before restarting.

## Getting started

- **Team admin:** open Daylens → **Create a new team**. The app walks you
  through it in about 5 minutes.
- **Teammates:** open Daylens → **Join my team**, then paste the invite
  code from your admin's message.

This repository only holds the installers.
